Tournament/event snapshots and tournament court sessions are committed to
IndexedDB before a save succeeds. A durable account/club-scoped queue retries
server writes while the app is open and connected. Pending edits survive a
reload. Newer edits are retained when an older write is acknowledged. Server
conflicts retain the local copy and show that sync needs attention.

The tournament menu includes Local tournament data: sync status, retry, and
Export local backup. Export before clearing browser data or reinstalling a PWA.

after server synchronization. Closing the PWA can pause synchronization.

Shared court reservations require server confirmation to prevent overlapping
allocations. Requests are journalled for retry; offline court availability is
not a confirmed reservation. Scoring passwords, login and official tournament
engine operations retain their existing server checks. Passwords and login
session tokens are not stored in the tournament sync queue. Protected score
sync may require password entry again after a reload.
