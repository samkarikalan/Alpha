If the compact endpoint is missing/unavailable, tournament scoring/approval now gives a clear error instead of using an unconfirmed local match.

The rules:
1. Assignment, score, finished result and approval intent are saved durably on the device before transmission. Offline work stays queued.
2. Group, Team and Knockout scoring, including scoring inside Tournament on the same device, must resolve the match from the server. A local-only assignment cannot start scoring. During play, points can be recorded locally offline and retried. Save & Close durably saves the finished result and sends it again.
3. Sent/Awaiting approval requires a server receipt for the finished score and winner. Organizer approval checks and updates the single server match independently of unrelated pending settings/session jobs. The organizer uses the server's score/winner, not a stale local copy.
4. Approved matches disappear from scoring lists. An open scoreboard locks when it learns of approval. The server rejects edits even from a stale or offline device. Pending rejected local work is retained for review.

Statuses: assigned -> playing -> submitted -> approved.
Local pending is a device delivery state; it is never treated as a server match status.
